# Security

Oddly has no server, login, analytics, or remote content. Calculation history and preferences remain in the app's local storage; the operating system may include app data in device backups.

For a vulnerability, use the repository's private vulnerability reporting feature if enabled. Do not include personal calculations, signing keys, or account credentials in a public report. If private reporting has not been enabled by the repository owner, ask for a private reporting channel without disclosing the vulnerability.

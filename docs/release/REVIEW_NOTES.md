# Notes for App Review

Oddly is a native offline calculator. No account, login credentials, server, payments, ads, or network connection are required. It uses local storage for calculation history, preferences, and discovered collectibles. It includes basic arithmetic, contextual percent, scientific shortcuts, history with recall/copy, appearance settings, and optional humor.

## Calculator behavior

Binary operations execute immediately, left to right, like a pocket calculator. For example, 2 + 3 × 4 = 20. The display updates the pending expression to 5 × after entering the second operator, so it does not imply algebraic precedence. Percent examples: 200 + 10% = 220; 200 × 10% = 20. Press equals again to repeat the last binary operation.

## Optional personalities and collectibles (complete disclosure)

Settings provides Calm, Playful (default), and Unhinged. Calm silences reactions and pauses new discoveries. Playful and Unhinged use the same interface and arithmetic; only humorous copy and its frequency differ. Ordinary quips appear at most every fourth or second completed calculation, respectively. Repeated identical answers suppress reactions. Humor never changes a result or blocks input.

Open the collection using the collection control to view all eight items and their hints. Each item is discovered locally once when the exact result below is produced with equals while Playful or Unhinged is enabled. Press AC before each example. Discovery state persists between launches. There are no remotely activated features, reviewer-specific modes, alternate application behavior, or additional concealed functionality. These small discoveries are also disclosed in the app description and collection hints.

Each first discovery also briefly decorates the mascot with a party hat and pastel sparks. Unhinged adds a small moustache and miniature companion faces. This finite decorative animation lasts about 1.2 seconds, stays inside the companion area, cannot receive input, and is disabled by Calm or the operating system's Reduce Motion setting. Reopening a screen does not replay old discoveries. Settings > Rediscover everything explicitly resets the local collection if users want to find them again.
